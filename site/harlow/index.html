Preview status

What works today. What is still coming.

Available in the preview

  • Object storage, document store, SQL database and queues
  • Apollo Events and Apollo KV
  • Resource groups, operations and the activity log
  • Members, roles, API tokens and audit

Planned or not available yet

  • Apollo Deploy builds: deployments stay queued until the build worker runs
  • Billing and pricing: usage counters are quotas, not charges
  • Custom domains, secrets and monitoring metrics
  • Compute lifecycle and AI services

The console marks anything that is unavailable instead of showing invented values. Access to the preview is by invitation while sign-ups are closed.
